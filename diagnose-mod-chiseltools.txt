== chiseltools (chiseltools) ==
97 of its 158 blocks and items have a value (61.4%); 0 are blacklisted on purpose (creative, technical or story items).
Vintage-E has no compatibility file for 'chiseltools'. Its raw materials only get a value if a recipe makes them, you pin them, or the mod gives them an emcValue attribute.

== Why the rest has no value ==
⚠ 61 items: nothing the mapper can read makes them.
  They're found in the world, dropped by creatures, bought from traders, or made by a machine or process Vintage-E doesn't know. The mapper only works values out from recipes, so raw materials like these have to be given a value.

  → Start with the families above: one value for a raw material fixes everything made from it.
