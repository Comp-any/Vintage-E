  → Start with the families above: one value for a raw material fixes everything made from it.

== Next steps ==
These are vinteng items made in a way Vintage-E can't read (its own machine, a custom recipe type, a drop it doesn't know). Vintage-E can be taught them with a compatibility file; the fastest way to get one is to ask:
  Post a comment on the Vintage-E Mod DB page: https://mods.vintagestory.at/show/mod/74355
    Suggested text: "Vintage-E 1.29.4 with vinteng ?: these items have no value: vinteng:crudeoilportion, vinteng:gasolineportion, vinteng:dieselportion, vinteng:lubricantportion, vinteng:lpgportion, vinteng:keroseneportion, vinteng:creosoteportion-wood, vinteng:creosoteportion-coal, vinteng:napthaportion, vinteng:heavyoilportion, vinteng:plasticpellet, vinteng:metalgear-copper, ... (28). /emc diagnose says nothing the mapper reads makes them."
  If the mod makes them in its own machine or recipe type, its author can help too: items can carry "attributes": { "emcValue": <n> } in their JSON, which Vintage-E reads directly.
  Meanwhile, values pinned on this server (/emc set, or BaseValues in the settings) fill the gap for your players right away.
  Put together a bug report to post (/emc diagnose bugreport)
