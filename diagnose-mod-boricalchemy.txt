== Boric Alchemy (boricalchemy) ==
2521 of its 2663 blocks and items have a value (94.7%); 0 are blacklisted on purpose (creative, technical or story items).
Vintage-E has no compatibility file for 'boricalchemy'. Its raw materials only get a value if a recipe makes them, you pin them, or the mod gives them an emcValue attribute.

== Next steps ==
These are Boric Alchemy (boricalchemy) items made in a way Vintage-E can't read (its own machine, a custom recipe type, a drop it doesn't know). Vintage-E can be taught them with a compatibility file; the fastest way to get one is to ask:
  Post a comment on the Vintage-E Mod DB page: https://mods.vintagestory.at/show/mod/74355
    Suggested text: "Vintage-E 1.29.4 with Boric Alchemy (boricalchemy) 3.3.4: these items have no value: boricalchemy:orthonitrophenol, boricalchemy:yttriumoxalate, boricalchemy:sodiumborohydride, boricalchemy:lanthanumcarbonate, boricalchemy:paranitrophenol, boricalchemy:ceriumdioxide, boricalchemy:thoriumhydroxide, boricalchemy:activatedcharcoal, boricalchemy:valericacid, boricalchemy:propionicacid, boricalchemy:butyricacid, boricalchemy:phosphoroxychloride, ... (76). /emc diagnose says nothing the mapper reads makes them."
  If the mod makes them in its own machine or recipe type, its author can help too: items can carry "attributes": { "emcValue": <n> } in their JSON, which Vintage-E reads directly.
  Meanwhile, values pinned on this server (/emc set, or BaseValues in the settings) fill the gap for your players right away.
  Put together a bug report to post (/emc diagnose bugreport)
