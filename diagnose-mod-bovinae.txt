== Fauna of the Stone Age: Bovinae (bovinae) ==
1026 of its 1058 blocks and items have a value (97.0%); 129 are blacklisted on purpose (creative, technical or story items).
Vintage-E has no compatibility file for 'bovinae'. Its raw materials only get a value if a recipe makes them, you pin them, or the mod gives them an emcValue attribute.

== Why the rest has no value ==
⚠ 16 items: nothing the mapper can read makes them.
  They're found in the world, dropped by creatures, bought from traders, or made by a machine or process Vintage-E doesn't know. The mapper only works values out from recipes, so raw materials like these have to be given a value.
    rawcheese (8): Raw antelope cheese (salted) (bovinae:rawcheese-antelope-salted), Raw bison cheese (salted) (bovinae:rawcheese-bison-salted), Raw buffalo cheese (salted) (bovinae:rawcheese-buffalo-salted), ...
    milkportion (4): Antelope milk (bovinae:milkportion-antelope), Bison milk (bovinae:milkportion-bison), Buffalo milk (bovinae:milkportion-buffalo), ...
    cheese (4): Antelope blue cheese (4 slices) (bovinae:cheese-antelope-blue-4slice), Bison blue cheese (4 slices) (bovinae:cheese-bison-blue-4slice), Buffalo blue cheese (4 slices) (bovinae:cheese-buffalo-blue-4slice), ...
  → Hold one and run /emc set <value>, or add it to BaseValues in ModConfig/vintagee.json. Everything made from it then gets a value by itself.
  → To do a whole mod at once for everyone, write a compatibility file: assets/vintagee/config/vintagee-emc-compat/bovinae.json with "requiresMod" and "values" (the files shipped with Vintage-E show the format). Please share it so it can be included.
  → Start with the families above: one value for a raw material fixes everything made from it.
⚠ 16 items have a recipe, but every recipe needs an ingredient that has no value.
  Give the ingredients a value and these follow by themselves. The ingredients holding back the most items:

  Post a comment on the Vintage-E Mod DB page: https://mods.vintagestory.at/show/mod/74355
    Suggested text: "Vintage-E 1.22.1 with Fauna of the Stone Age: Bovinae (bovinae) 1.0.3: these items have no value: bovinae:milkportion-antelope, bovinae:milkportion-bison, bovinae:milkportion-buffalo, bovinae:milkportion-eland, bovinae:cheese-antelope-blue-4slice, bovinae:cheese-bison-blue-4slice, bovinae:cheese-buffalo-blue-4slice, bovinae:cheese-eland-blue-4slice, bovinae:rawcheese-antelope-salted, bovinae:rawcheese-bison-salted, bovinae:rawcheese-buffalo-salted, bovinae:rawcheese-eland-salted, ... (16). /emc diagnose says nothing the mapper reads makes them."
  If the mod makes them in its own machine or recipe type, its author can help too: items can carry "attributes": { "emcValue": <n> } in their JSON, which Vintage-E reads directly.
  Meanwhile, values pinned on this server (/emc set, or BaseValues in the settings) fill the gap for your players right away.
  Put together a bug report to post (/emc diagnose bugreport)
