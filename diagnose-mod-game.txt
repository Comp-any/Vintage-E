== Vintage Story (game) ==
8128 of its 8145 blocks and items have a value (99.8%); 648 are blacklisted on purpose (creative, technical or story items).

== Why the rest has no value ==
⚠ 12 items: nothing the mapper can read makes them.
  They're found in the world, dropped by creatures, bought from traders, or made by a machine or process Vintage-E doesn't know. The mapper only works values out from recipes, so raw materials like these have to be given a value.
    figurehead (4): figurehead-eidolon (game:figurehead-eidolon), figurehead-erel (game:figurehead-erel), figurehead-seamonster (game:figurehead-seamonster), ...
    metalplate (2): Stainless steel plate (game:metalplate-stainlesssteel), Uranium plate (game:metalplate-uranium)
    ingot (2): Stainless steel ingot (game:ingot-stainlesssteel), Uranium ingot (game:ingot-uranium)
    crushed (1): Crushed peridotite (game:crushed-peridotite)
    spear (1): Long erel feather stem (game:spear-generic-erel)
    arrow (1): Short erel feather stem (game:arrow-erel)
    bonyremains (1): Bony Cow Skull (game:bonyremains-cowskull-up)
  → Hold one and run /emc set <value>, or add it to BaseValues in ModConfig/vintagee.json. Everything made from it then gets a value by itself.
  → Start with the families above: one value for a raw material fixes everything made from it.
⚠ 3 items have a recipe, but every recipe needs an ingredient that has no value.
  Give the ingredients a value and these follow by themselves. The ingredients holding back the most items:

    Stainless steel plate (game:metalplate-stainlesssteel): 1 item(s) wait on it. (nothing makes it: give it a value)  why? (/emc diagnose item game:metalplate-stainlesssteel)
    Work item (Stainless steel) (game:workitem-stainlesssteel): 1 item(s) wait on it. (blacklisted: allow it, or give it a value)  why? (/emc diagnose item game:workitem-stainlesssteel)
    Uranium ingot (game:ingot-uranium): 1 item(s) wait on it. (nothing makes it: give it a value)  why? (/emc diagnose item game:ingot-uranium)
    Uranium plate (game:metalplate-uranium): 1 item(s) wait on it. (nothing makes it: give it a value)  why? (/emc diagnose item game:metalplate-uranium)
    Work item (Uranium) (game:workitem-uranium): 1 item(s) wait on it. (blacklisted: allow it, or give it a value)  why? (/emc diagnose item game:workitem-uranium)
    Platinum ingot (game:ingot-platinum): 1 item(s) wait on it. (in a value loop)  why? (/emc diagnose item game:ingot-platinum)
