== Why the rest has no value ==
⚠ 15 items: nothing the mapper can read makes them.
  They're found in the world, dropped by creatures, bought from traders, or made by a machine or process Vintage-E doesn't know. The mapper only works values out from recipes, so raw materials like these have to be given a value.

    pickaxe (2): Greater pickaxe (game:pickaxe-summonedobject-pickaxe1-unstable), Brilliant pickaxe (game:pickaxe-summonedobject-pickaxe2-unstable)
    saw (2): Greater saw (game:saw-summonedobject-saw1-unstable), Brilliant saw (game:saw-summonedobject-saw2-unstable)
    hoe (2): Greater hoe (game:hoe-summonedobject-hoe1-unstable), Brilliant hoe (game:hoe-summonedobject-hoe2-unstable)
    knife (2): Greater knife (game:knife-summonedobject-knife1-unstable), Brilliant knife (game:knife-summonedobject-knife2-unstable)
    shovel (2): Greater shovel (game:shovel-summonedobject-shovel1-unstable), Brilliant shovel (game:shovel-summonedobject-shovel2-unstable)
    spear (1): Long erel feather stem (game:spear-generic-erel)
    arrow (1): Short erel feather stem (game:arrow-erel)
  → Hold one and run /emc set <value>, or add it to BaseValues in ModConfig/vintagee.json. Everything made from it then gets a value by itself.
  → Start with the families above: one value for a raw material fixes everything made from it.
