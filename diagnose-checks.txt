== Recipes that make EMC out of nothing ==
If a recipe's output is worth more than its ingredients, a player can craft it and burn it for free EMC, over and over. The mapper prevents this for values it works out itself; trader prices, guesses, fallback values and pins can break that guarantee.

== Blacklisted ingredients holding recipes back ==
⚠ 1 blacklisted items are the only thing 14 recipes wait for:
  A blacklisted item has no value, so no recipe that needs it can value its output. Often that's right (a creative-only part). When the blacklist entry is a mistake, allowing the item values everything made from it.
  Terminus teleporter thanatos coupling (game:returndeath-returndeath1): 14 recipe(s) wait on it. (Vintage-E's value files: 'game:returndeath-*')

  → Allow the item (or give it a value) if players can really get it. Leave it if it's creative-only or a story item.
